# Grupo Maíma — site institucional

Site estático (HTML, CSS e JavaScript) do Grupo Maíma: MAÍMA (SU), LDA e M.Maíma Transitário, LDA.

- `index.html` — conteúdo em português (idioma principal)
- `script.js` — traduções em francês e inglês, menu móvel e formulário de contacto
- `styles.css` — aspeto visual (cores do grupo: verde, vermelho e azul-escuro)
- `assets/` — logótipos, fotografias e ícone

## Publicar
O site é publicado com o GitHub Pages (Settings → Pages → Branch `main`, pasta `/root`).
Para usar o domínio `www.grupomaima.ao`, adicionar o domínio em Settings → Pages e criar no DNS
um registo CNAME `www` → `<utilizador>.github.io`. Os registos de e-mail (MX) não devem ser alterados.
